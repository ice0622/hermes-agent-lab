# Health Log

筋トレ・食事・体重の記録だけを担当する。**分析と助言は `health-today` の仕事**なので、
このスキルでは数値の評価をしない。

## When to Use

ユーザーが**実際にやったこと・食べたこと**を報告したとき。

- 「ベンチ40キロ8回3セット」「ラットプルダウン47キロ10回×3」
- 「昼はパン3つ食べた」「カフェラテ350mlとワッフル」
- 「体重64.2」
- `bp 40 8,8,8` `w 64.2` `m サラダチキン` のような定型
- 「さっきの取り消して」

使わない: 「あと何食べればいい？」「今日何すればいい？」（→ `health-today`）、
週の振り返り（→ `health-report`）。

## Quick Reference

| 目的 | コマンド |
|---|---|
| 筋トレ（同一重量） | `health bp 40 8,8,8` |
| 筋トレ（セット別重量） | `health bp 40x8,37.5x8,35x6` |
| 自重種目 | `health pu 5,4,3` |
| 体重 | `health w 64.2` / `health w 64.2 15.3`（体脂肪率つき） |
| 食事（定型） | `health m サラダチキン, おにぎり*2` |
| **食事（自由文）** | `health nl "昼はパン3つとカフェラテ350ml"` |
| メニュー表示 | `health t pull` |
| 直前を取り消す | `health undo` |
| 直近の記録 | `health last` |

種目コード: `bp`ベンチプレス `sq`スクワット `dl`デッドリフト `lpd`ラットプルダウン
`row`ローイング `sp`ショルダープレス `sr`サイドレイズ `dbc`ダンベルカール
`lpr`レッグプレス `pu`懸垂。全一覧は `health t push|pull|legs`。

## Procedure

1. **入力が既に定型なら、解釈せずそのまま実行する。**

   先頭が種目コード / `w` / `m` / `t` / `undo` / `last` で始まっていれば、
   **考えずに `health <入力そのまま>` を実行して結果を返す。**
   これが最も安く速い経路で、モデルの判断を一切挟まない。

2. 自由文で**食事**が含まれるなら `health nl "<自由文そのまま>"` に渡す。
   自分で栄養価を計算しない。マスタとの突き合わせは `nl` の仕事。

3. 自由文で**筋トレ**が含まれるなら、種目コードと重量・レップに直して
   `health <code> <重量> <レップ,レップ,...>` を実行する。
   例: 「ベンチ40キロ8回8回6回」→ `health bp 40 8,8,6`

4. 1回の発言に筋トレと食事が両方あれば、**別々のコマンドとして順に実行する**。
   まとめようとしない。

5. 実行結果を**1行以上必ず返す**。無反応が最悪で、入ったか分からないと
   次から投げてもらえなくなる。

6. `!` の警告が出たら、それも省略せず伝える。
   特に「マスタに無いので栄養価0で記録」と「複数該当したので○○にした」は
   黙って通すとカロリーが静かにずれる。

## Pitfalls

- **`health` が PATH に無い。** 先に `ln -sf <repo>/skills/health/bin/health ~/.local/bin/health`
  を実行しておく。`${HERMES_SKILL_DIR}` からの相対パスは、開発用シンボリックリンク経由だと
  リンク先ではなくリンク元を指すので使わない。
- **DB が無い。** `health init` と `health import` が済んでいるか確認する。
- **栄養価を自分で計算しない。** マスタの値を使わないと、同じ食品の記録が日によってずれる。
- **記録をエラーで止めない。** マスタに無い食品は栄養価0の「未知」として通る仕様。
  それが正しい挙動なので、名前を勝手に別の品に置き換えない。
- 曖昧な量（「パン3つ」の種類、「プロテイン」の製品）は `nl` が `?` 付きで報告する。
  それをユーザーに転送する。こちらで決めない。
- **同じ日に `w` を2回打つと上書きになる。** 警告が出るのでそれも伝える。

## Verification

`health last` に今入れた記録が出ること。
食事なら `health today` の摂取量が増えていること。
