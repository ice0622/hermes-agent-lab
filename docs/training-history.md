### 読み取れること

1. **増量を目標にしているが、実測は減量している。** 1月平均 66.5kg → 直近 64.3kg。
   摂取が消費を下回っている状態が半年以上続いている。
2. **筋力が2025年12月から停滞。** 最初の4ヶ月で +6.7kg 伸びたあと、8ヶ月間 45.5〜50.0kg で
   横ばい。体重が落ちている期間に筋力が伸びないのは自然な帰結。
   ナチュラルでこの重量帯なら、体重を戻せば重量も戻る可能性が高い。
3. **頻度が2026年2月以降に週1.2〜1.6回まで落ちた。** 停滞のもう一つの要因。
   7月に週2.3回まで戻したが、8月は19日で2回。
4. **7/30 と 8/3 に有酸素（トレッドミル 傾斜9% / 4.5km/h / 30分）を追加している。**
   増量目標と方向が逆。消費を増やしている。
5. 分割は実質 **Push / Pull / Legs** で固まっている（2026年1月に本人が Push/Pull/legs と明記）。
   ただし**曜日は固定されていない**。マスタは曜日ではなく分割名で持つべき。
